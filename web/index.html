This browser can't talk to USB devices (it has no Web Serial). Open this page in Chrome or Edge on a computer to send transactions and flash firmware. Everything else here works.

How a transaction gets checked

The device works out the hash.
Not the computer.

This page sends a demo Safe transaction to your Cardputer over USB. The Cardputer rebuilds the transaction's hash from its fields, shows you what it does, and only compares the hash this page claims. A wrong claim turns it red.

      Flash the signer onto a Cardputer
      
    
      One image at address 0: the bootloader, the partition table and the signer, built from this
      repository by web/build.sh. The browser checks its SHA-256 before writing.
      
    
      This replaces whatever is on the board. To keep what's there, save a full image
      first: esptool.py read_flash 0 ALL backup.bin.
